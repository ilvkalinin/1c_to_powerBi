# Playbook: STAGE_3_IMPLEMENTATION

Открывается только явным разрешением после нужной валидации. Начинай с
критичных переиспользуемых продуктов. Ни одна колонка не появляется в SQL без
mapping; SQL детерминированный, с явными колонками/типами и осмысленными CTE.
Миграции отдельные, удаление не автоматизировать, индекс — только по фактам и
плану. Перед опасной операцией показать SQL пользователю.
