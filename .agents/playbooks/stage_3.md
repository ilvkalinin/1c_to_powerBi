# Playbook: STAGE_3_IMPLEMENTATION

Открывается только явным разрешением на полный Stage-3 пакет после нужной
валидации. Начинай с критичных переиспользуемых продуктов. Ни одна колонка не
появляется в SQL без mapping; SQL детерминированный, с явными
колонками/типами и осмысленными CTE. Миграции отдельные, удаление не
автоматизировать, индекс — только по фактам и плану.

До одобрения пакета покажи пользователю его точный SQL-план либо неизменяемые
ссылки на reviewed SQL, все затрагиваемые объекты, DDL/DML, проверки, rollback
и критерий готовности. После такого одобрения выполняй эти опасные действия
как единый пакет без нового согласования каждого statement. Новое согласование
нужно только при материальном расхождении с одобренным планом.

Для нового physical mart или full rebuild до admission также полностью пройди
`mart_delivery_preflight.md`; его checklist и evidence входят в reviewed plan.
