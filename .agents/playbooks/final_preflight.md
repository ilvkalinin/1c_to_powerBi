# Playbook: final preflight

Сначала классифицируй ответ: `REPORT_HANDOFF` или `DIRECT_REPLY`. Подготовь
полный точный текст и запусти ровно один общий gate:

```sh
scripts/preflight_message.sh --report-handoff <файл-с-полным-текстом>
# или
scripts/preflight_message.sh --direct-reply <файл-с-полным-текстом>
```

Ненулевой код запрещает `final`, включая пустой ответ. `REPORT_HANDOFF`
допустим только после полного закрытия пакета; перед ним выполни audit
неразрешённых вопросов. `DIRECT_REPLY` отвечает только на прямой вопрос,
команду остановки или запрос решения и не передаёт результат отчёта, статус
проекта, handoff или обещание дальнейшей проверки. В обоих случаях текст
обязан соответствовать `Сделано → Результат → Дальше`.

Этот gate объединяет проверку режима и проверку формата; его успешный запуск
действителен только для переданного текста. Промежуточные `commentary` не
обязаны иметь этот шаблон, но всегда заканчиваются одним конкретным действием
или самодостаточным вопросом.

`ПРОДОЛЖАЮ РАБОТУ` — исключительно `commentary`; общий gate намеренно не имеет
режима progress-final. Если сообщение передаёт ход работ или результат блока,
это `REPORT_HANDOFF`, а не `DIRECT_REPLY`.

`final` без режима запрещён. Полная действующая форма сообщений и audit — в
этом playbook и `communication.md`; исторический reference для них не
используется.
