# Playbook: STAGE_2_SERVER_VALIDATION

Выполняй только накопленные `VALIDATION_PENDING` read-only проверки. Сохраняй
выполненный SQL, результат и доказательство; реализацию автоматически не
начинай. Power BI snapshot/export не является обязательным входом: достаточно
source-side проверки точных PBIT/M/DAX правил.

Проверяй реальные типы, ключи, NULL, cardinality, states, объём, joins,
границы времени, дубли и control values. До запроса зафиксируй ожидаемый
результат. Наблюдаемое расхождение не исправляй: сохраняй current result по
BR-018 и отдельно описывай методическое улучшение.

Все накопленные проверки, сохранение доказательств и обновление относящихся к
ним артефактов — внутренние шаги согласованного пакета; не запрашивай на них
отдельное подтверждение. Архивный reference не является нормативным источником.
