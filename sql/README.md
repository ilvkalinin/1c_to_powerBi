# SQL

SQL конкретных витрин пока не создан: отсутствуют фактическая структура источника, требования первого отчёта, разрешённая целевая схема и выбранный механизм миграций.

После подтверждения дизайна файлы создаются раздельно по необходимости:

```text
sql/
├── migrations/
├── schemas/
├── staging/
├── core/
├── marts/
├── functions/
├── indexes/
├── grants/
├── maintenance/
└── tests/
```

Не создавать все каталоги заранее. Для простой витрины допустим только `schemas`, `marts`, `grants` и `tests`; загрузка, индексы и промежуточные слои добавляются по подтверждённой необходимости. Каждое изменение схемы оформляется миграцией с rollback-инструкцией.
