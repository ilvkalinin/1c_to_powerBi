# SQL

Этот каталог содержит SQL только для явно одобренных пакетов. Актуальное
разрешение, scope и состояние определяются `AGENTS.md`, project gate и ledger,
а не этим обзорным файлом.

Внутри согласованного пакета файлы создаются раздельно по необходимости:

```text
sql/
├── migrations/
├── schemas/
├── staging/
├── core/
├── marts/
├── functions/
├── indexes/
├── grants/
├── maintenance/
└── tests/
```

Не создавать все каталоги заранее. Для простой витрины допустим только
`schemas`, `marts`, `grants` и `tests`; загрузка, индексы и промежуточные слои
добавляются по подтверждённой необходимости. Каждое изменение схемы
оформляется миграцией с rollback-инструкцией. Reviewed SQL-план и одобрение
пакета покрывают все его включённые statement и тесты; новое согласование
нужно только при выходе за scope.
