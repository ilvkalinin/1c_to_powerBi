Отчет «Отчет по ИП»
Описание отчета: отчет показывает проведение тренировок ИП с ЧК, которые занесены в Gymmy.
Фильтры:
	•	Клуб
	•	Месяц 
Метрики:
	•	Кол-во услуг – количество занесенных в систему тренировок за выбранный период
	•	УЧК – кол-во уникальных клиентов, которые потребили услуги за выбранный период
	•	Регулярность – среднее число услуг на 1 клиента
Формула: Регулярность = кол-во услуг ÷ УЧК
	•	Тренеров – кол-во ИП, которые занесли тренировки за выбранный период
	•	Услуг на 1 тренера – среднее число услуг, которое занес каждый тренер ИП
Формула: Услуг на 1 тренера = Кол-во услуг ÷ Тренеров 
Визуализации:
	•	Таблица «Структура тренировок по типу услуги» показывает распределение всех тренировок по услугам, которые потребляют клиенты. Отображается кол-во тренировок в штуках и в процентах от общего числа
	•	Диаграмма «Динамика кол-ва проданных услуг» показывает рейтинг клубов по числу занесенных тренировок. Помогает проводить работу с ИП по занесению тренировок в систему.
	•	Таблица «Таблица основных показателей по сотрудникам» показывает значение показателей для каждого сотрудника выбранных клубов за выбранный период с указанием кодов ЧК, которые эти услуги потребили
	•	Диаграмма «Динамика кол-ва проданных услуг» показывает Количество занесенных тренировок по дням в выбранных клубах
