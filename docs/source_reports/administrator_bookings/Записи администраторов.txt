Отчет «Записи администраторов»
Описание отчета: отчет показывает выручку ДПФУ, которая сформирована записями на занятия, сделанными администраторами клубов. 
Фильтры:
	•	Год, месяц (занятия)
	•	Выберите день (занятия)
	•	Выберите клуб
	•	Выберите администратора
	•	Выберите формат тренировки (поле «Формат тренировки» из карточки номенклатуры в Gymmy)
Метрики:
	•	Всего выручки по записям администраторов – сумма оказанных групповых услуг ДПФУ, на которые клиенты были записаны через администраторов рецепции
	•	Всего записей администраторов – количество записей, совершенных администраторами за выбранный период
	•	Средняя цена записи - средняя стоимость списания одной услуги ДПФУ, записанной через администратора рецепции
Формула: Средняя цена записи = Всего выручки по записям администраторов ÷ Всего записей администраторов
Визуализации:
	Сверху расположен блок карточек, который показывает фактические значения показателей за выбранный период.
	Слева в центральной части расположен рейтинг клубов по объему выручки ДПФУ, полученной через запись клиентов на занятия администраторами рецепции.
	Справа в центральной части отчета находится столбчатая диаграмма, показывающая выручку ДПФУ от записей клиентов администратора за выбранный период. Информация на диаграмме может быть отображена по дням / месяцам / годам отчета.
В правой нижней части расположена таблица с указанием выручки, количества записей и средней цене записи по каждому администратору и каждой номенклатуре урока, на которую администраторы записывают клиентов.
