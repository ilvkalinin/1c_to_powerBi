# Runbook

Текущий статус: `BLOCKED` для исполнения. Нет подключения, объектов, механизма миграций и расписания.

## Безопасный порядок развёртывания

1. Подтвердить окружение, целевую схему, права и backup/rollback.
2. Показать production SQL пользователю и получить явное разрешение.
3. Выполнить миграцию утверждённым инструментом.
4. Запустить загрузку и проверки с ожидаемыми результатами.
5. Проверить свежесть, время, объём и контракт Power BI.
6. Зафиксировать результат и отклонения.

## Сбой и откат

- Остановить дальнейшие шаги и сохранить безопасные логи без секретов.
- Установить затронутый объект и последнюю успешную точку.
- Использовать rollback-инструкцию конкретной миграции; не удалять объекты автоматически.
- Повторить reconciliation и проверку Power BI после восстановления.

## Изменение структуры 1С

Снять новые метаданные, сравнить mapping, отметить затронутые контракты, обновить ADR/SQL/тесты и развернуть как отдельную миграцию. До проверки несовместимого изменения не считать данные свежими.

Конкретные команды, владельцы, SLA, диагностика и порядок ручного refresh добавляются с первой витриной.
