# S3-MB-LOAD-AUTH-001: разрешение initial load

Дата: 2026-08-20. Статус: `COMPLETED / VALIDATED`.

Пользователь явно разрешил загрузить данными из read-only 1С две существующие
пустые таблицы: `mart.membership_receipt_movement` и
`mart.membership_contract_kpi_unit`.

Граница пакета: детерминированный DML по подтверждённым mapping, атомарный
bounded rebuild BR-003 и source-to-target reconciliation. Не входят: DDL,
изменение 1С, переключение Power BI и расписание refresh.

Пользователь также явно указал, что показывать точный SQL до запуска не нужно,
если он реализует ранее подтверждённую логику и схемы. SQL сохраняется в
репозитории и проходит локальный review; методика не меняется.

После выявления blocker `list_contract_price` пользователь отдельно разрешил
прочитать только Power Query M, формирующий `_Спр Абонементы.price`, чтобы
воспроизвести существующий выбор при множественных парах цен. Разрешение не
распространяется на Excel-файлы, другие Power Query или изменение Power BI.

## Выполнение и контроль

Загрузка выполнена одной атомарной транзакцией на горизонт BR-003
`[2025-01-01, 2027-01-01)`. Исходная 1С оставалась read-only; DDL, изменение
Power BI и расписание refresh не выполнялись.

Переписанная source-проекция сформировала 293 577 строк за 9,44 секунды.
Дальнейшее ускорение сквозного запуска требует отдельной оптимизации передачи
широкого набора полей между VM-1 и VM-2: это не изменение SQL-расчёта и не
выполнялось в рамках текущего initial load.

Пользователь подтвердил такой отдельный performance-пакет 2026-08-20.
Разрешены измерение и реализация оптимизации канала VM-1→VM-2 для этих двух
фактов с целевым SLA полного refresh в одну минуту. Не разрешены изменение
mapping/grain, DDL, изменение 1С, переключение Power BI или расписание refresh.

## Закрытие performance-пакета

Пользователь принял измеренную производительность 2026-08-20: source SQL
формирует 293 577 строк за 9,44 секунды; основной binary COPY занимает
80–95 секунд, полный bounded refresh — около 3–3,5 минут. Оптимизация
компрессии не требуется. Экспериментальный FDW-путь не принят: из-за
`mvarChar` он не быстрее и не остаётся в рабочем загрузчике.
