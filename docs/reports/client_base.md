## Риск временной логики

`CONFIRMED`: отчёт описывает состояние клиентской базы «на дату».

`CONFIRMED`: действующий SQL абонементов фильтрует только дату окончания, а запрос пакетов — дату чека. Эти фильтры захардкожены и не соответствуют динамической политике проекта.

`ASSUMPTION`: для восстановления состояния на дату могут понадобиться договоры, абонементы или движения, созданные до нижней границы показываемой истории, но действующие внутри неё. Поэтому проектное окно результата нельзя автоматически применять как фильтр по дате создания исходной записи.

`CONFIRMED`: на VM-2 не требуется сохранять client-level snapshots. Идентификатор клиента используется временно внутри source-side расчёта для `DISTINCT`, активности и retention, после чего передаются только агрегаты.
