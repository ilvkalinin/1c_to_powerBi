# Требования отчёта: «Отчет по посещаемости клиентов с долгами»

Статус: `BUSINESS ANALYSIS COMPLETE / TECHNICAL VALIDATION DEFERRED`.

Договорный отчёт №22, блок «Гостеприимство». Анализ выполнен локально по
бизнес-описанию, полному M/DAX, снимкам страницы и модели Power BI. Подключений
к 1С/PostgreSQL, выполнения SQL и создания объектов не было.

## Назначение

Отчёт контролирует случаи, когда клиент фактически пришёл в клуб в выбранный
день и имеет задолженность по неподтверждённой услуге. Он не показывает всех
должников клуба: когорта всегда ограничена клиентами с посещением выбранного
клуба и даты.

Пользователи — все, у кого уже есть доступ к данному Power BI-отчёту. Их
управленческое действие — контролировать задолженность клиента, посетившего
клуб, и причину её возникновения по услуге. ПДн в детальных визуалах разрешены
этой аудитории.

## Подтверждённые показатели

| Показатель | Текущая формула / правило | Статус |
|---|---|---|
| `Долг на начало дня` | для клиентов, посетивших выбранный клуб в `D`: сумма задолженностей по ключу `код клиента × предварительная запись`, сформированных до `D` и оставшихся непогашенными на начало `D` | CONFIRMED — DAX `Долг` |
| `Долг на конец дня` | та же когорта посетителей, но движения включены по `D`; учитываются только ещё непогашенные предварительные записи | CONFIRMED — DAX `Долг_на_конец_дня` |
| `Погашено за день` | сумма долга, существовавшего до `D` у посетивших клиентов и закрытого в `D` подтверждением или отменой | CONFIRMED — DAX `Погашено долгов` |
| `Погашено долгов всего` | тот же факт погашения без ограничения когортой посетителей | CONFIRMED — DAX `Погашено долгов всего` |
| `Новые долги за день` | `Долг на конец дня - (Долг на начало дня - Погашено за день)` | CONFIRMED — активная DAX-мера; соответствует описанию только после проверки контрольных значений |
| `Количество клиентов с долгами` | число уникальных кодов среди посетивших клиентов, у которых на конец дня остаётся положительный долг | CONFIRMED — DAX `Кол-во клиентов с долгами` |
| `Количество посещений` | число уникальных клиентов с посещением в контексте дня и клуба; текущая мера `DISTINCTCOUNT(Посещения_общий[Код])` сохраняется | CONFIRMED — решение пользователя 2026-07-31: долги считаются по людям, поэтому и визиты считаются по людям |
| `Посещение клиентов с долгами` | число уникальных клиентов с долгом в когорте посетителей для каждого дня | CONFIRMED — визуал и DAX |

Отрицательные движения суммы в Power Query приводятся к знаку долга через
`СуммаИтог = IF(ВидДвижения = 1, -Сумма, Сумма)`.

## Детализация и время

| Представление | Одна строка / логическая единица | Статус |
|---|---|---|
| Карточки и подневный график долга | выбранная дата × клуб × множество уникальных посетивших клиентов | CONFIRMED current calculation |
| «Общая сумма долга по каждому клиенту» | выбранная дата × клуб посещения × клиент | CONFIRMED visual и DAX |
| «Долги клиентов по использованным услугам» | выбранная дата × клуб посещения × клиент × предварительная запись × услуга; технический ключ услуги ещё не доказан | CONFIRMED consumer grain / VALIDATION_PENDING key |
| Временная граница | начало дня: движения `< D`; конец дня: движения `<= D`; событие посещения относится к `D` | CONFIRMED current DAX |

История прямо не названа; BR-003 даёт общую календарную политику. По BR-014
отчёт обновляется ежедневно и должен быть доступен не позднее 08:30 по Москве;
питающие витрины должны завершать обновление раньше. Точное время старта и
допустимая длительность будут измерены на серверной валидации.

## Текущая модель Power BI

- `Посещения_общий = UNION(Посещения_2025, Посещения_2026)`;
- `НеподтвержденныеУслуги` собирается отдельно по годам и затем объединяется;
- измерения `СпрКлубы`, `Спр.Клиенты`, `СпрСотрудники`, `_СпрДата` фильтруют
  факты связями many-to-one; на снимке модели нет прямой связи календаря или
  клуба с таблицей неподтверждённых услуг;
- DAX сам формирует набор посетителей на выбранную дату и применяет его к
  движениям долга. Поэтому готовый дневной итог долга без ключа клиента не
  воспроизведёт текущие фильтры.
