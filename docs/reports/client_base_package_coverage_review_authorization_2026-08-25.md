# Авторизация read-only review: пакеты в «Клиентской базе»

- Дата: 2026-08-25
- Отчёт: «Клиентская база» (`client_base`)
- Этап: `STAGE_2_SERVER_VALIDATION`
- Пакет: `client_base_package_coverage_2026-08-25`
- Основание: явное поручение пользователя «посмотреть где в клиентскую базы не добавлены пакеты» от 2026-08-25 после закрытия пакета второго месяца вовлечения.
- Статус: `VALIDATED` — см. [результат review](client_base_package_coverage_review_2026-08-25.md).

## Разрешённый scope

1. Read-only mapping/reuse-review текущего source extract и физического
   `mart.client_base_daily` относительно подтверждённого требования базы:
   уникальные люди с действующим абонементом **или детским пакетом** на дату
   снимка.
2. Read-only source controls ветви `Document346.VT4913` для установления:
   источника ребёнка, взрослого договора, клуба, даты начала, даты окончания,
   состояний чека и раздельной дедупликации `club`/`network` на контрольной
   дате.
3. Read-only comparison с текущим абонементным universe и с агрегированным
   target только в объёме, не раскрывающем PII или client-level строки.
4. Документирование exact отсутствующих ветвей, их количества и условий
   включения/исключения; подготовка решения только если current Power BI rule
   или source-state semantics не позволяют воспроизвести результат однозначно.

## Явные границы

- Только `REPEATABLE READ READ ONLY` на 1С и read-only запросы к mart.
- Запрещены DDL, DML, `COPY`, создание любых объектов, изменение источника,
  изменение `mart.client_base_daily` и изменения Power BI.
- BR-037 о положительных продажах/возвратах действует для витрин вовлечения;
  он не расширяется на «Клиентскую базу» данным review. Здесь проверяется
  current подтверждённая ветвь пакетов и фиксируется необходимость отдельного
  решения, если требуется применить иной sales/return scope.

## Критерий закрытия

- подтверждённый source-to-target/reuse mapping;
- воспроизводимые control values и нулевые отклонения в controls, применимых к
  существующей абонементной ветви;
- численно установленный package-only gap текущего target; либо доказано его
  отсутствие;
- зафиксированное отсутствие изменений в target и Power BI.
