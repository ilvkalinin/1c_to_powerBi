# Авторизация: инвентаризация и приоритизация незавершённых витрин

Статус: `COMPLETED / READ-ONLY PORTFOLIO REVIEW`.

Дата согласования: 2026-08-24.

## Согласованный scope

Пользователь подтвердил самостоятельный read-only пакет после ответа о том,
что реализованы не все витрины. В пакет входят:

- сверка `docs/catalogs/data_products.md`, checkpoint ledger, активного
  пакета и связанных mapping/contract/ADR/evidence-артефактов;
- единый перечень реализованных, готовых к самостоятельному admission и
  заблокированных/требующих дополнительной технической валидации продуктов;
- приоритизация следующей волны по зависимостям, готовности evidence и
  повторному использованию уже реализованных общих фактов;
- исправление только документальных расхождений, найденных в этих источниках.

## Граница

Разрешены только локальные read-only review и документальные изменения.
Не входят в пакет: подключение к источнику, Stage 2 server validation,
DDL/DML, запуск загрузчиков, изменение Power BI, смена бизнес-правил или
выбор новой витрины к реализации.

## Критерий закрытия

Есть один проверяемый инвентаризационный отчёт с полным списком текущих
не реализованных продуктов, их состоянием и доказательной причиной,
отдельным ранжированием кандидатов следующей волны и явно указанными
блокерами. `data_products`, ledger, active package и project gate согласованы;
пакет закрыт атомарным коммитом.
