# Решение об атрибуции СКУД: `employee_presence_day`

- Дата: 2026-08-28
- Отчёт: `employee_workload`
- Основание: явное решение пользователя «оставить без сотрудника» в ответ на
  результаты EPD-V01--V05.

## Решение

Посещения exact current-M domain, у которых `Reference225` не даёт ровно
одного сотрудника, не исключаются и не получают произвольного сотрудника.
Они сохраняются отдельно без `employee_id` с двумя наблюдаемыми статусами
атрибуции: `NO_EMPLOYEE` (29,431 visit IDs) и `MULTIPLE_EMPLOYEES` (708 visit
IDs). Их будущая агрегатная гранулярность — `presence_date × club_id ×
attribution_status`.

Персональный `employee_presence_day` содержит только 439,808 source visit IDs
с одной подтверждённой связью сотрудника; его уже измеренный control равен
350,346 `employee × date × club` группам и
141,383,578.78226548333333983510 минутам. Это целевая методика, а не
утверждение о воспроизведении полного current-M результата.

## Границы

Решение не разрешает DDL, DML, `COPY`, создание объектов, target-подключение
или изменения Power BI. Оно отменяет только запрет на проектирование двух
раздельных продуктов присутствия; source extract, types, key, DDL, loader,
reconciliation и physical admission требуют нового согласованного Stage 3
пакета.
