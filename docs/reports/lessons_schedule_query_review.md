## Подтверждённые правила Power Query

- `Волшебная статистика` выбирает проведённые `Document279` с началом после
  2024-04-01, связывает их с `InfoRg8675` и классифицирует время: до 12:00 —
  утро, до 17:00 — день, иначе вечер. Она исключает «Бойцовский клуб» и
  «Свободное посещение настоль…», а игровой зал оставляет только для
  Пушкинского/Pushkinsky VIP.
- `РС_СостояниеПредЗаписи` оставляет `Enum448.EnumOrder = 4`, считает строки
  по занятию и использует среднюю `Document279.Fld3222` как вместимость.
- Обе ветви `Все уроки` разворачивают интервал `[start, end)` на 5-минутные
  слоты. Ключ текущего M составлен только из даты и времени слота, без клуба и
  помещения; он не может быть ключом целевого факта.
- Для `Document279` current M исключает `Marked = 1`, но не фильтрует
  `Posted`; отдельная «Волшебная статистика» фильтрует `Posted = 1`.
- Для `Document329` current M требует `Posted = 1` и один GUID статуса,
  соединяет отмены через `Document313`, но не фильтрует `Marked`.
- «После» определяется как `lesson_end_at - document_created_at < 0`, то есть
  документ создан уже после окончания, хотя описание страницы говорит «после
  начала». Это подтверждённое расхождение между описанием и расчётом.

## DAX: значимые правила

- Рейтинг бесплатного урока — `SUM(Посетило) / _МаксПлан`; план — 90% внешней
  вместимости для бесплатных уроков, 20 для платных, с явными детскими
  исключениями 5/6 мест.
- Цвет ХУК использует процент заполнения и календарные будни/выходные. В
  описании красный — низкая загрузка, а текущая колонка `ВкраснойЗонеY/N`
  возвращает для этой же зоны «Синий»: визуальная семантика цвета нуждается в
  сверке до переноса.
- Занятость залов равна количеству 5-минутных слотов × `5/60`; плановые часы
  задаются константами 16 для будней и 14 для выходных, умноженными на число
  помещений в текущем фильтре.
- Текущая мера «Занесено не в срок» делит количество поздних distinct дат
  регистрации на все distinct даты регистрации, поэтому не соответствует
  заявленной доле услуг, если в один день внесено несколько занятий.
- Доля ГП использует особый знаменатель: дети для переключателя и детского
  клуба; женщины-взрослые в остальных случаях; все посещения для Пушкинского
  и Пушкинского VIP.

## Граница PostgreSQL / Power BI

После валидации PostgreSQL должен готовить только квалифицированные занятия и
их интервалы, стабильные идентификаторы и предагрегированные счётчики
прибывших/посетивших. В DAX остаются доли, рейтинг, четыре цветовые зоны,
ранжирование, сравнение периодов и фильтр-контекст. Внешние параметры
вместимости и категории не переносятся в SQL без подтверждённого источника.
