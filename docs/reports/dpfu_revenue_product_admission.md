`client_key` требуется в факте ДПФУ для `DISTINCTCOUNT` УЧК и должен быть
стабильным между датами, клубами и refresh. Его физический источник уже
подтверждён SV-054: `AccumRg7575.Fld7576` и `AccumRg7646.Fld7648` покрыты на
100%.

- `S3-ADMISSION-001`, выполненный 2026-08-13 в `BEGIN READ ONLY`, проверил
  `Reference141X1._Code` на точном квалифицированном scope ДПФУ;
- для 41 682 distinct client ID найдены 41 682 reference-строки, 0 null,
  0 пустых и 0 повторяющихся `_Code`;
- первый релиз использует `Reference141X1._Code::text` одновременно как
  `client_key` и `client_code`; исходный `bytea` ID остаётся на VM-1 и не
  передаётся в Power BI.

Дополнительно S3-ADMISSION-002 подтвердил ключ движения: в текущем scope
ДПФУ 813 670 строк и 0 повторов как по

## Закрытый технический риск: объединение source extract

S3-ADMISSION-004, выполненный 2026-08-13 в `BEGIN READ ONLY`, показал, что
две ветви при независимом выполнении дают ожидаемый квалифицированный набор:

| Ветка | Строки | Количество | Выручка |
|---|---:|---:|---:|
| `AccumRg7575` | 812 793 | 825 550,000 | 953 835 414,35 |
| `AccumRg7646` | 892 | 886,000 | 47 497,50 |

Кандидатный объединённый CTE при проверке вернул другой набор строк, поэтому
он отозван и не используется. Безопасная реализация сохраняет семантику
`UNION ALL`: runner читает две подтверждённые ветви отдельными source-query в
одном `REPEATABLE READ, READ ONLY` snapshot и добавляет обе в одну временную
таблицу VM-2 без дедупликации. Перед заменой факта runner сравнивает сумму
строк, количества и выручки каждой ветви. Это не меняет состав строк, а
исключает непроверенный объединённый запрос.

## Решение: горизонт первого заполнения

Текущий подтверждённый source SQL ДПФУ выбирает период
`2024-01-01 ≤ Period < 2027-01-01`. По BR-003 в августе 2026 года стандартный
горизонт — `2025-01-01 ≤ Period < 2027-01-01`. Пользователь 2026-08-14
подтвердил, что для всех витрин BR-003 имеет приоритет над статическими датами
в старых запросах.

Read-only S3-ADMISSION-007 показал, что за 2024 год в точном текущем source
scope находятся 309 379 движений, количество 318 817,000 и выручка
314 773 989,12. Эти движения не войдут в первую загрузку ДПФУ; это
согласованное изменение горизонта, а не скрытое исключение из BR-003.
До отдельного разрешения пользователя никакие DML не выполняются.
