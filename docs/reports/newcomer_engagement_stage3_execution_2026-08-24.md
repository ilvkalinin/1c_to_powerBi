## Атомарная загрузка

`scripts/load_newcomer_engagement_milestone.py --rebuild`:

1. получает source-side набор в локальный временный binary-COPY файл;
2. проверяет число source строк по `COPY rowcount`;
3. копирует файл во временную таблицу VM-2 и сверяет число строк и уникальность
   ключа до DML основной таблицы;
4. получает advisory lock, затем в одной транзакции удаляет старый набор и
   вставляет проверенный staging-набор;
5. при ошибке делает rollback; состояние старой витрины сохраняется.

Для подключений к обеим VM применяется общий policy
`initial attempt + five operational retries` из `scripts/mart_connection.py`.
