- Production DDL/DML — только после явного разрешения.
- Нельзя выдумывать таблицы, поля, связи и бизнес-правила.
- Конкретная витрина не реализуется без требований, mapping и архитектурного решения.
- Не подключаются dbt, оркестраторы, контейнеры и сторонние ETL без согласования.
- Между ВМ передаются только необходимые колонки и строки целевого периода, по возможности уже отфильтрованные и агрегированные на источнике.
- Не создавать постоянную полную реплику сырых регистров в базе витрин.

Bootstrap создан, но база не исследована. `psql` и другие PostgreSQL CLI не найдены в локальном `PATH` на 2026-07-23.
