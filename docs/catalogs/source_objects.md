# Каталог физических источников

Дата актуализации: 2026-08-05.

Каталог составлен по существующим `docs/mappings/*.md` и дополнен read-only
инвентаризацией PostgreSQL-каталога 2026-08-05. Все подтверждённые физические
отношения находятся в схеме `public`; их реальные имена начинаются с `_` и
находятся в нижнем регистре (например, `public._accumrg7575`). Имена в
таблице ниже сохранены в форме из mapping, чтобы не менять бизнес-ссылки на
источники. Физические типы, кардинальности и бизнес-семантика состояний 1С
проверяются по плану в
[серверной валидации](../source_metadata/server_validation_2026-08-05.md).

Mapping `membership_board` полностью повторно использует набор физических
источников `membership_receipts`; чтобы не дублировать одинакового потребителя
в каждой строке, это наследование фиксируется здесь и в каталоге продуктов.
