## Меры DAX

```DAX
Всего выручки по записям администраторов =
SUM('Записи администраторов'[Выручка])
```

```DAX
Всего записей администраторов =
SUM('Записи администраторов'[Количество записей])
```

```DAX
Средняя цена записи =
DIVIDE(
    [Всего выручки по записям администраторов],
    [Всего записей администраторов]
)
```

Средняя цена не хранится физически и не суммируется.

## Граница вычислений

PostgreSQL:

- использует `AccumRg7575.Fld7586` для обеих веток;
- определяет автора и должность на дату записи;
- применяет подтверждённые правила форматов и отмен;
- `NULL` формата заменяет на `Малая группа`;
- считает документ один раз при нескольких движениях;
- агрегирует до контрактной гранулярности.

Power Query:

- подключается к готовому view;
- назначает типы и русские имена;
- не выполняет joins, фильтры форматов, distinct или группировки.

DAX выполняет только три меры выше и интерактивную фильтрацию.

## Не включать

- `InfoRg6612` и дневные планы;
- клиента и его ФИО/код;
- тренера;
- возраст;
- дату создания записи как активную дату модели;
- среднюю цену как колонку;
- сырые строки `AccumRg7575`;
- отдельную таблицу групповых и предварительных записей.

## Условия принятия

1. Фактические типы ключей.
2. Уникальность целевого ключа.
3. Сверка числа документов до и после связи с движениями.
4. Сохранение суммы `Fld7586` без размножения.
5. Проверка общих измерений и orphan.
6. Контрольные значения карточек.
7. Измерение времени source-side отбора и локального view.
