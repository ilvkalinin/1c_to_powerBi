# Качество и сверка

Тест содержит: назначение, SQL, ожидаемый результат, допуск, источник ожидания, фактический результат и статус `NOT RUN | PASS | FAIL | BLOCKED`.

Минимальное покрытие: строки и объекты, ключи и дубли, `NULL`, ссылки, периоды и пропуски дат, суммы, сохранение/размножение строк после `JOIN`, удаление/проведение/исправления, повторный запуск и производительность.

Без заранее записанного ожидаемого результата тест не считается успешно пройденным. Сейчас тесты не создаются, потому что нет объекта, ключа и контрольных значений.
