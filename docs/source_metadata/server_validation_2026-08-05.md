## SV-032 — эффект кадрового join и `Table.Distinct` в CRM

Статус до запуска: `VALIDATION_IN_PROGRESS`.

В текущем M строки взаимодействий соединяются с кадровыми настройками по

тот же результат и сохранит все самостоятельные строки `InfoRg7146`.

Статус: `VALIDATED` на независимом срезе января 2026.

| Шаг текущей логики | Строк |
|---|---:|
| После SQL-фильтров воронок и Jivo | 158 979 |
| После текущего разворачивания кадрового join | 113 423 |
| После `Table.Distinct` | 98 798 |
| Убрано `Table.Distinct` | 14 625 |
| Эквивалентный `EXISTS` вместо кадрового join | 98 798 |

звонка при этом не теряются. Переход от имени к ID сотрудника остаётся
