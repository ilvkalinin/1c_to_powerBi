# Реестр отсутствующих объектов источника

Назначение: полный перечень физических объектов, отсутствующих в фактической
базе `gymdb.public` и относящихся к договорным отчётам, для одного обращения к
системному администратору. Реестр пополняется только доказательствами из
server validation; не заменяет исходные таблицы альтернативными именами без
проверки.

Правило пользователя от 2026-08-11: при каждом новом доказанном отсутствии
физического объекта сразу дополнять этот реестр и единый запрос системному
администратору; не создавать для такого объекта отдельное обращение.

Дата актуализации: 2026-08-18.

## Полнота списка

SV-006 сверил 94 physical dependencies, извлечённые из mapping договорных
отчётов: 91 таблица найдена, две зависимости из перечня выше отсутствовали, а
`Reference141` подтверждён как физический alias `_reference141x1`. SV-014
отдельно обнаружил отсутствующий `Document275` среди реальных типов
регистраторов. SV-090 подтвердил поставку трёх исторически отсутствующих
объектов. CR-V05 и MF-V07 добавили `Enum471` и `Enum526` как текущие
непоставленные physical dependencies для label mapping CRM-статусов и типов
оплаты. Это не завершает business- или кардинальные проверки остальных
объектов.

Табличные части `Document275` и другие объекты из полного metadata 1С не
включены: они не являются доказанными зависимостями текущих SQL/M/DAX и не
проверялись как нужные отчётам. Добавлять их в запрос без evidence запрещено.

`Reference141` не является отсутствующим объектом: его физическая реализация
в этой базе — `_reference141x1`.
