# Реестр отсутствующих объектов источника

Назначение: единый список объектов, отсутствующих в фактической базе
`gymdb.public`, чтобы запросить их у системного администратора одним пакетом.
Реестр пополняется только доказательствами из server validation; не заменяет
исходные таблицы альтернативными именами без проверки.

Дата актуализации: 2026-08-11.
