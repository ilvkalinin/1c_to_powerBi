# Реестр отсутствующих объектов источника

Назначение: полный перечень физических объектов, отсутствующих в фактической
базе `gymdb.public` и относящихся к договорным отчётам, для одного обращения к
системному администратору. Реестр пополняется только доказательствами из
server validation; не заменяет исходные таблицы альтернативными именами без
проверки.

Дата актуализации: 2026-08-11.

отчётов: 91 таблица найдена, две зависимости из перечня выше отсутствуют, а
`Reference141` подтверждён как физический alias `_reference141x1`. SV-014

регистраторов. Это все доказанные на 2026-08-11 отсутствующие таблицы в

включены: они не являются доказанными зависимостями текущих SQL/M/DAX и не
проверялись как нужные отчётам. Добавлять их в запрос без evidence запрещено.

`Reference141` не является отсутствующим объектом: его физическая реализация
в этой базе — `_reference141x1`.
